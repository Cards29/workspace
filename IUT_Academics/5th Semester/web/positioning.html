CSS Position Property Demo

1. position: static (The Default)

Elements are in the normal flow. top, left, etc., are ignored.

Static Parent (position: static)
Static Child

This paragraph flows right after the static child.

2. position: relative

The element is shifted from its normal position, but **it still reserves its original space** in the flow.

Relative Parent (position: static - Default)
Relative Child

Notice how this paragraph starts where the **Relative Child's original space was** (not where the element visually moved to). Relative positioning preserves space.

3. position: absolute

The element is removed from the flow and positioned relative to its nearest positioned ancestor.

Relative Parent (position: relative)
Absolute Child

This paragraph ignores the Absolute Child and moves up to occupy the empty space left by its removal from the flow. The Absolute Child is positioned relative to the blue parent's borders.

4. position: fixed

The element is removed from the flow and positioned relative to the Viewport. **Scroll the box below** to see the effect.

This area is internally scrollable.

This tall content forces the container to scroll.

The **Fixed Button** is attached to the main **browser window** (viewport), not this smaller scrollable box. You will see it outside and above this entire section, and it won't move when this box scrolls, but it *will* move if you scroll the entire web page (which you can't do inside this preview, but trust me, it's fixed to the browser frame!).
